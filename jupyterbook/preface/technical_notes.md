# Technical Notes and Prerequisites

The examples were originally developed with Python 3.9 and matplotlib 3.7.1. Because Python 3.9 has reached end of life, readers should use a currently supported Python 3 release and a current matplotlib release. I also make use of Jupyter notebook cell magics. I assume familiarity with basic Python programming, NumPy, pandas, and even matplotlib. In Part I (Prose), the premise is that you can make a plot, but now you want to polish it. Other parts assume less background knowledge. For those needing to review some Python before approaching this text, I recommend [*A Whirlwind Tour of Python*](https://jakevdp.github.io/WhirlwindTourOfPython/) and [*Python Data Science Handbook*](https://jakevdp.github.io/PythonDataScienceHandbook/), both by Jake VanderPlas.
